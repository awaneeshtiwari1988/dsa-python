# DSA in Python

Data structures and algorithms practice in Python — interview preparation for Applied/Research Scientist roles at FAANG and product-based companies, organized by pattern rather than dumped by problem number.

Python is my primary language for ML/DL/Quantum work, so this repo doubles as general coding fluency practice and a place to keep vectorized, idiomatic Python sharp alongside the research-heavy repos.

---

## Structure

Problems are grouped by pattern, not chronologically — this is deliberate: recognizing *which* pattern a new problem maps to is the actual interview skill, more than having memorized any single solution.

```
dsa-python/
├── arrays-two-pointers/
├── hashing/
├── trees-and-tries/
├── graphs/
├── dynamic-programming/
├── greedy-and-backtracking/
└── system-design-adjacent/   # LRU cache, rate limiter, consistent hashing, etc.
```

Each problem folder includes:
- The problem statement (linked, not reproduced in full)
- My solution with comments explaining the approach
- Time/space complexity analysis
- A short note on which pattern this problem taught or reinforced
